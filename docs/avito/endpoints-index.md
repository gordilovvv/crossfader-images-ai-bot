Правила формирования XML/Excel-файлов для автозагрузки: структура, обязательные и необязательные поля, параметры категории «Музыкальные инструменты / Аккордеоны, гармони, баяны», доставка, продвижение, примеры.

## Объявления (items)

`POST /core/v1/accounts/{userId}/vas/prices` — Получение стоимости услуг продвижения и доступных значков для списка объявлений.
`POST /core/v1/accounts/{user_id}/calls/stats/` — Получение агрегированной статистики звонков пользователя за период.
`GET /core/v1/accounts/{user_id}/items/{item_id}/` — Получение данных об объявлении (статус, применённые услуги).
`PUT /core/v1/accounts/{user_id}/items/{item_id}/vas` — Применение дополнительной услуги к объявлению (устарело, используйте v2).
`GET /core/v1/items` — Получение списка объявлений авторизованного пользователя с фильтрацией по статусу и категории.
`POST /core/v1/items/{item_id}/update_price` — Обновление цены объявления по его ID.
`PUT /core/v2/accounts/{user_id}/items/{item_id}/vas_packages` — Применение пакета дополнительных услуг к объявлению (устарело, используйте v2).
`PUT /core/v2/items/{itemId}/vas/` — Применение одной или нескольких услуг продвижения к опубликованному объявлению.
`POST /stats/v1/accounts/{user_id}/items` — Получение статистических счётчиков (просмотры, контакты, избранное) по списку объявлений.
`POST /stats/v2/accounts/{user_id}/items` — Получение детальных статистических показателей по профилю с группировкой по объявлениям, дням, неделям или месяцам.
`POST /stats/v2/accounts/{user_id}/spendings` — Получение статистики расходов профиля по типам за период.

## Управление остатками (stock-management)

`POST /stock-management/1/info` — Получение информации об остатках товара для переданных объявлений.
`PUT /stock-management/1/stocks` — Обновление количества товара (остатков) для переданных объявлений.

## Автозагрузка (autoload)

`GET /autoload/v1/profile` — Получение настроек профиля автозагрузки пользователя (устарело).
`POST /autoload/v1/profile` — Создание или редактирование настроек профиля автозагрузки (устарело).
`POST /autoload/v1/upload` — Запуск выгрузки объявлений из файла по ссылке, указанной в профиле.
`GET /autoload/v1/user-docs/node/{node_slug}/fields` — Получение полей, зависимостей и допустимых значений для конкретной категории.
`GET /autoload/v1/user-docs/tree` — Получение дерева категорий Авито в виде массива.
`GET /autoload/v2/items/ad_ids` — Получение идентификаторов объявлений из файла автозагрузки по ID объявлений на Авито.
`GET /autoload/v2/items/avito_ids` — Получение ID объявлений на Авито по идентификаторам из файла автозагрузки.
`GET /autoload/v2/profile` — Получение настроек профиля автозагрузки пользователя (актуальная версия).
`POST /autoload/v2/profile` — Создание или редактирование настроек профиля автозагрузки (актуальная версия).
`GET /autoload/v2/reports` — Получение списка отчётов автозагрузки с сортировкой по убыванию даты.
`GET /autoload/v2/reports/items` — Получение данных по конкретным объявлениям из файла автозагрузки по их ID.
`GET /autoload/v2/reports/last_completed_report` — Получение сводной статистики последней завершённой выгрузки (устарело).
`GET /autoload/v2/reports/{report_id}` — Получение сводной статистики конкретной выгрузки по ID отчёта (устарело).
`GET /autoload/v2/reports/{report_id}/items` — Получение результатов обработки каждого объявления в конкретной выгрузке.
`GET /autoload/v2/reports/{report_id}/items/fees` — Получение информации о списаниях за размещение объявлений в конкретной выгрузке.
`GET /autoload/v3/reports/last_completed_report` — Получение сводной статистики последней завершённой выгрузки (актуальная версия).
`GET /autoload/v3/reports/{report_id}` — Получение сводной статистики конкретной выгрузки по ID отчёта (актуальная версия).
