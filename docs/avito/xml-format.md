# Формат файлов автозагрузки (XML / Excel)

## Общие требования к XML

- Максимум 50 000 объявлений в файле
- Кодировка UTF-8
- Корневой элемент `<Ads>` с атрибутами `target="Avito.ru"` и `formatVersion="3"`
- Каждое объявление — элемент `<Ad>` внутри `<Ads>`
- Названия параметров чувствительны к регистру, только латиница

```xml
<?xml version="1.0" encoding="UTF-8"?>
<Ads target="Avito.ru" formatVersion="3">
  <Ad>
    <!-- параметры объявления -->
  </Ad>
</Ads>
```

## Параметры объявлений

В таблицах ниже: **XML-тег** / *Excel-столбец* (в Excel колонки называются на русском).

---

### Идентификация

| XML-тег | Excel-столбец | Обяз. | Описание |
|---------|---------------|-------|----------|
| `Id` | Уникальный идентификатор объявления | ✅ | Уникальный ID, который вы присваиваете сами. Не менять. До 100 знаков: цифры, рус/англ буквы, `, \ / ( ) [ ] - =` |
| `AvitoId` | Номер объявления на Авито | — | Заполнять только если объявление уже есть на Авито и нужно его связать (например, изменился Id). Для нового — не заполнять |

```xml
<Id>xjfdge4735202</Id>
<AvitoId>742817810</AvitoId>
```

---

### Даты размещения

| XML-тег | Excel-столбец | Обяз. | Описание |
|---------|---------------|-------|----------|
| `DateBegin` | Начало размещения | — | Дата/время публикации. Форматы: `dd.MM.yyyy`, `dd.MM.yy`, `yyyy-MM-dd`, `+ HH:mm` или ISO 8601 |
| `DateEnd` | Окончание размещения | — | Дата/время снятия. Те же форматы. Прошедшая дата — объявление не обработается |

```xml
<DateBegin>24.09.24 13:00</DateBegin>
<DateEnd>24.09.24 13:00</DateEnd>
```

---

### Размещение и продвижение

| XML-тег | Excel-столбец | Обяз. | Описание |
|---------|---------------|-------|----------|
| `ListingFee` | Способ размещения | — | `Package` (по умолчанию) / `PackageSingle` / `Single` |
| `AdStatus` | Услуга продвижения | — | Услуга продвижения (см. значения ниже). По умолчанию: `Free` |

**Значения `AdStatus`:**
- `Free` — без продвижения
- `Highlight` — Выделение цветом (7 дней)
- `XL` — XL-объявление (7 дней)
- `x2_1` / `x2_7` / `x5_1` / `x5_7` / `x10_1` / `x10_7` — до N раз больше просмотров на 1 или 7 дней
- `x15_1` / `x15_7` / `x20_1` / `x20_7` — то же, доступно в некоторых регионах/категориях

```xml
<ListingFee>PackageSingle</ListingFee>
<AdStatus>x10_7</AdStatus>
```

### Контакты

| XML-тег | Excel-столбец | Обяз. | Описание |
|---------|---------------|-------|----------|
| `ManagerName` | Контактное лицо | — | Имя менеджера, до 40 символов |
| `ContactPhone` | Номер телефона | — | Один российский номер с кодом города/оператора |
| `ContactMethod` | Способ связи | — | `По телефону и в сообщениях` (по умолч.) / `По телефону` / `В сообщениях` |
| `InternetCalls` | Интернет звонки | — | `Да` / `Нет` |
| `CallsDevices` | Устройства для приёма звонков | — | ID устройств (через `|` в Excel, через `<Option>` в XML) |

```xml
<ManagerName>Иван Петров</ManagerName>
<ContactPhone>+7 495 777-10-66</ContactPhone>
<ContactMethod>В сообщениях</ContactMethod>
<InternetCalls>Да</InternetCalls>
<CallsDevices><Option>123456789</Option><Option>67890123</Option></CallsDevices>
```

### Местоположение

| XML-тег | Excel-столбец | Обяз. | Описание |
|---------|---------------|-------|----------|
| `Address` | Адрес | ✅ (если нет координат) | Полный адрес до 256 символов |
| `Latitude` | Широта | — | Альтернатива Address, вместе с Longitude |
| `Longitude` | Долгота | — | Альтернатива Address, вместе с Latitude |
| `SellerAddressID` | Идентификатор адреса | — | ID адреса из профиля (вместо Address) |

```xml
<Address>Москва, ул. Тверская, 1</Address>
<!-- или -->
<Latitude>55.778669</Latitude>
<Longitude>37.587964</Longitude>
```

### Описание

| XML-тег | Excel-столбец | Обяз. | Описание |
|---------|---------------|-------|----------|
| `Title` | Название объявления | ✅ | До 50 символов. Без цены, контактов, слова «продам» |
| `Description` | Описание объявления | ✅ | До 7500 символов. HTML-теги `p, br, strong, em, ul, ol, li` — только внутри `CDATA` |

```xml
<Title>Баян Weltmeister</Title>
<Description><![CDATA[
Отличный баян в <strong>идеальном состоянии</strong>.
<ul><li>41 правая клавиша</li><li>120 басов</li></ul>
]]></Description>
```

### Фото и видео

| XML-тег | Excel-столбец | Обяз. | Описание |
|---------|---------------|-------|----------|
| `Images` | Ссылки на фото / Названия фото | ✅ | До 10 фото. По ссылке — атрибут `url`, по имени файла — атрибут `name`. JPEG/PNG, до 25 МБ каждая |
| `VideoURL` | Ссылка на видео | — | YouTube `https://www.youtube.com/watch?v=*` или Rutube `https://rutube.ru/video/*/` |
| `VideoFileURL` | URL видеофайла | — | Прямая ссылка на .mp4/.mov/.hevc/.webm или Яндекс Диск. Внутри CDATA. 5 сек — 3 мин, до 500 МБ. Требует включённой доставки |

```xml
<!-- по URL -->
<Images>
  <Image url="https://example.com/photo1.jpg"/>
  <Image url="https://example.com/photo2.jpg"/>
</Images>

<!-- по имени файла (при загрузке архивом) -->
<Images>
  <Image name="photo1.jpg"/>
  <Image name="photo2.jpg"/>
</Images>

<!-- В Excel: url через | -->
<!-- http://img.test.ru/a.jpg | http://img.test.ru/b.jpg -->
```

### Категория товара (Музыкальные инструменты)

| XML-тег | Excel-столбец | Обяз. | Описание |
|---------|---------------|-------|----------|
| `Category` | Категория | ✅ | `Музыкальные инструменты` |
| `GoodsType` | Вид товара | ✅ | Подкатегория, например `Аккордеоны, гармони, баяны` |
| `AdType` | Вид объявления | ✅ | `Продаю своё` / `Товар приобретен на продажу` / `Товар от производителя` |
| `Condition` | Состояние | ✅ | `Новое` / `Б/у` |
| `Price` | Цена | — | Целое число в рублях |

```xml
<Category>Музыкальные инструменты</Category>
<GoodsType>Аккордеоны, гармони, баяны</GoodsType>
<AdType>Товар приобретен на продажу</AdType>
<Condition>Новое</Condition>
<Price>25000</Price>
```

### Доставка

| XML-тег | Excel-столбец | Обяз. | Описание |
|---------|---------------|-------|----------|
| `Delivery` | Способ доставки | — | Одно или несколько: `Выключена`, `ПВЗ`, `Курьер`, `Постамат`, `Свой курьер`, `Свой партнер СДЭК`, `Свой партнер Деловые Линии`, `Свой партнер ПЭК`, `Свой партнер Почта России`, `Самовывоз с онлайн-оплатой` |
| `WeightForDelivery` | Вес (Для Доставки) | — | Вес в кг |
| `LengthForDelivery` | Длина (Для Доставки) | — | Длина в см |
| `HeightForDelivery` | Высота (Для Доставки) | — | Высота в см |
| `WidthForDelivery` | Ширина (Для Доставки) | — | Ширина в см |
| `ReturnPolicy` | Возвраты | — | Только если `Delivery` = `ПВЗ`. Варианты: `По любой причине — 15 минут` / `3 дня` / `7 дней` / `14 дней` / `По браку — 24 часа` |
| `DeliverySubsidy` | Субсидирование доставки | — | Только при `ПВЗ` или `Постамат`. Скидка в рублях (от 30 до 70% цены). С 01.07.2025 только числовой формат |

```xml
<Delivery>
  <Option>ПВЗ</Option>
  <Option>Курьер</Option>
</Delivery>
<!-- В Excel: ПВЗ | Курьер -->

<WeightForDelivery>2</WeightForDelivery>
<DeliverySubsidy>100</DeliverySubsidy>
```

### Настройка цены целевого действия (Promo)

Используется в категориях «Товары», «Услуги», «Транспорт» с соответствующими тарифами.

| XML-тег | Excel-столбец | Обяз. | Описание |
|---------|---------------|-------|----------|
| `Promo` | Настройка цены целевого действия | — | `Manual` / `Auto_1` / `Auto_7` / `Auto_30` |
| `PromoAutoOptions` | Настройка цены целевого действия: автоматическая | — | Обязателен при `Auto_*`. Регион + бюджет |
| `PromoManualOptions` | Настройка цены целевого действия: ручная | — | Обязателен при `Manual`. Регион + ставка + лимит в день |

```xml
<!-- Авто-режим -->
<Promo>Auto_7</Promo>
<PromoAutoOptions>
  <Item><Region>Москва</Region><Budget>30000</Budget></Item>
</PromoAutoOptions>

<!-- Ручной режим -->
<Promo>Manual</Promo>
<PromoManualOptions>
  <Item><Region>Санкт-Петербург</Region><Bid>1000</Bid><DailyLimit>10000</DailyLimit></Item>
</PromoManualOptions>

<!-- В Excel: Москва|30000 (авто) или Москва|1000|10000 (ручной) -->
```

```xml

<Ads target="Avito.ru" formatVersion="3">

    <InstrumentType>Баян</InstrumentType>
    <Brand>Weltmeister</Brand>
    <Images>
      <Image url="https://example.com/bayan.jpg"/>
    </Images>
  </Ad>
</Ads>
```

## Закрытие и удаление объявлений

- **Закрыть одно**: удалить строку/элемент `<Ad>` из файла — объявление уйдёт в архив
- **Закрыть все**: загрузить файл только со столбцом `Id`, в первой строке написать `stop`
- **Удалить навсегда**: из архива вручную через ЛК → через 30 дней удалится

> После удаления размещать похожее объявление можно только через 30 дней (иначе засчитается дублем).

## Загрузка файла

### Вручную (ЛК)
Авто → Настройки → Настроить ручную загрузку → выбрать файл (+ ZIP с фото если `ImageNames`).

### По ссылке (расписание)
Авто → Настройки → Настроить загрузку по ссылке → указать URL файла (http/https, прямое скачивание) → настроить расписание. До 3 ссылок на разные файлы.

> Расписание игнорируется, если у объявления заполнен `DateBegin`.
